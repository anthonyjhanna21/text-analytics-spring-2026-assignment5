# Results Folder

This folder will contain model outputs after the notebook API experiment is run.

Expected files:

- `raw_model_outputs.csv`: one row per model, prompt strategy, and test example
- `results_matrix.csv`: summary metrics by model and prompt strategy

These files are generated by `notebooks/lm_evaluation.ipynb` after adding `GOOGLE_API_KEY` and `HF_TOKEN` to `.env` and setting `RUN_API_CALLS = True`.
